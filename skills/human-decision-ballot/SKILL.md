# Human Decision Ballot

## Overview
A busy person answers a numbered multiple-choice list in a minute. The same
questions asked open-ended, one at a time, take an evening and come back
vague. Do the thinking for them, show your pick, and make every option
something you could act on immediately.

Core principle: **one batch, numbered questions, lettered options, your
recommendation first, evidence beside each.**

## When to Use
- More than one decision is waiting on a person.
- A long run is ending and you need direction for the next one.
- The person will read on a phone, between other things.

Not for a single yes/no that blocks you right now; just ask it.

## Ballot shape
```
DECISIONS NEEDED (3). Reply like "1a 2b 3a", or add a word after any number.

1. <Question in one line, phrased as a choice.>
   a) <Option, concrete enough to act on.>  RECOMMENDED: <one-line reason>
   b) <Option.>
   c) <Option.>
   Evidence: <file path, image, or number that bears on it>

2. ...
```

Rules for the shape:
1. **Recommended option is (a)** and says why in one line.
2. **Each option is an action**, not a direction ("cut the intro to 2 lines",
   not "make the intro shorter").
3. **Evidence beside each question**: the image, number, or file that would
   change someone's mind. If there is no evidence, say so.
4. **Order by what blocks the most work.** Questions that block nothing go last
   or wait for the next ballot.
5. **One batch.** Do not drip questions across several messages.
6. **Do not re-ask answered questions.** Check earlier answers first. If an old
   answer seems wrong now, say so as a new question citing the old answer.
7. **Keep each question independent** so "1a 2c" never contradicts itself. If
   two decisions interact, merge them into one question with combined options.

## Recording answers
- Copy the person's reply word for word next to the question, with the date.
- A condition in the answer ("b, unless it hurts load time") becomes a task to
  measure, not a judgment you make. Measure it, then report which branch held.
- A new suggestion from the person that conflicts with an earlier decision is
  built and tested as asked, at full strength, with a one-line note naming the
  conflict. Do not argue it down before trying it.
- A gesture ("make it feel heavier") gets turned into a precise spec you hand
  back for a yes before building.

## Common Mistakes
| Mistake | Fix |
|---|---|
| "What do you think we should do about X?" | Give options and a pick |
| Ten questions, all equal weight | Order by what they block; defer the rest |
| Options that need a follow-up to act on | Make each option concrete |
| Re-asking last week's settled question | Read prior answers first |
| Treating "unless X" as your call | Measure X and report |
